Updated 04/19/2022 02:59 PM
Certain keyboard shortcuts do not work on GeForce NOW when playing on a Steam Deck with an external keyboard. How can I fix that?
Most keyboard shortcuts work except for certain system hotkeys like Ctrl+Alt+F4. This hotkey, and similar function keys, switch to a new command line session, since SteamOS is based on Linux. At this time, we do not have a fix for those hotkeys.
