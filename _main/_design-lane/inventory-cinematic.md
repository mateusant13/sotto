# PanelSetA vs PanelSetB

Both files export exactly **five** layouts, and they are assigned to scene slots by index: `panelSetA = { glassCards, hairline, paper, quotes, ledger }` serves scenes **01–05** (cafe, rainglass, dustlight, analog, shelves) through `scene.panelVariant`; `panelSetB = { feed, bubbles, timeline, chips, gutter }` serves scenes **06–10** (lampblack, rooftop, tideline, ember, fieldnotes). Every layout takes the identical `PanelProps` contract from `shared.tsx` — `{ scene, segments, live, paused, elapsed, onToggle, onClear }` — and every layout re-implements the same three-band skeleton: a header band, one scrolling middle band wrapped in `useAutoScroll`, and a footer band with counters and controls. Both sets also pull from the same kit: `GhostButton`, `LevelMeter`, `LiveDot`, `initials`, `wordsOf`, `useAutoScroll`, `StreamText`, and the eight `Icon*` glyphs.

**PanelSetA (01–05)**
| layout | scene purpose | middle-band structure |

**Is B a variation of A?** No. They are two independent families that share a kit and a contract, not one parameterised component: A's middle bands are card/table/page metaphors (per-segment surfaces, printed rules, zebra rows), B's are stream/conversation/rail/grouping metaphors (inline log lines, directional bubbles, drawn spine, chapter blocks, margin gutter). The only structural properties they have in common are inherited from `shared.tsx` and from `PanelProps`. The two sets do, however, contain two matched pairs across the split: `Paper` (A) and `Gutter` (B) are the only layouts with `blur: 0` and a light surface (`#F6EDE1` and `rgba(243,239,230,0.94)`, both using `.scroll-light`), and `GlassCards`/`Quotes`/`Bubbles`/`Chips` are the four that wrap each segment in its own rounded surface while `Hairline`/`Ledger`/`Feed`/`Timeline`/`Gutter`/`Paper` do not.

# Duplicate / near-duplicate groups

### `cinematic` — one skeleton, ten colour grades
All ten themes share the identical `vars` key set (`--panel, --panel-2, --ink, --dim, --faint, --line, --accent, --accent-ink, --hover, --caption-ink, --caption-accent, --scrim, --shadow`), the identical component tree, and the identical caption geometry; they differ only in colour values plus the caption class / reveal / ghost class below. There are exactly **four** reveal modes for ten designs.

- **Exact caption-treatment duplicates — `tideline` and `north-fog`.** Byte-identical caption class `font-body font-light text-[clamp(20px,2.6vw,30px)] leading-[1.45] text-[var(--caption-ink)]`, identical `reveal: "blur"`, identical default ghost class. Only the palettes differ (`#63bfb2` seafoam vs `#7fbb9c` sage).
- **Same family, 1px apart — `midnight-rain` vs `tideline`/`north-fog`.** `midnight-rain` is the same `font-body font-light text-[clamp(20px,…vw,30/31px)] leading-[1.45]` string with `2.7vw/31px` instead of `2.6vw/30px`, and `reveal: "fade"` instead of `"blur"`.
- **Display-italic trio — `warm-hour`, `last-reel`, `motel-glow`.** All three are `font-display italic … text-[var(--caption-ink)]` with `reveal: "fade"` and ghost class `font-display italic`; `warm-hour` = `text-[clamp(21px,2.8vw,33px)] leading-[1.4]` (no weight), `last-reel` = `font-medium text-[clamp(21px,2.8vw,32px)] leading-[1.4]`, `motel-glow` = `font-medium text-[clamp(22px,3vw,35px)] leading-[1.38]`. So `last-reel` is `warm-hour` plus `font-medium` minus 1px, and `motel-glow` is `last-reel` plus 1–3px and plus the glow in `--shadow`.
- **Typewriter pair — `study-light` and `paper-moon`.** Both `font-mono` with `reveal: "type"` (the only two type reveals). `study-light` = `text-[clamp(16px,2.1vw,24px)] leading-[1.6]`; `paper-moon` = `font-medium uppercase tracking-[0.16em] text-[clamp(14px,1.8vw,20px)] leading-[1.7]`.
- **Tracked-body pair — `velvet-dusk` and `quiet-streets`.** Both `font-body font-normal` with `leading-[1.5]` and an added tracking (`0.035em` vs `0.09em`) at `clamp(19px,2.5vw,29px)` vs `clamp(18px,2.3vw,27px)`; the only difference besides colours and sizes is `reveal: "rise"` vs `"fade"`.
- **Light-panel singleton:** `paper-moon` is the only theme whose `--panel` is light (`rgba(240,241,238,0.94)`) — but its caption is still light-on-dark (`--caption-ink #f4f6f4` over `--scrim rgba(5,6,10,0.62)`).

### `cinematic-1` — five caption variants across ten scenes, paired 2+2+2+2+1
- **`wide` + Newsreader — `cafe` and `tideline`.** Same `captionVariant`, same `captionFont: F.news`, both `weight 400` vs `300`, `size 34` vs `32`, `leading 1.34` vs `1.4`, `tracking -0.012em` vs `-0.014em`, `textTransform: none`.
- **`tight` + Inter 300 — `rainglass` and `fieldnotes`.** `size 28` vs `27`, `weight 300` both, `leading 1.5` vs `1.52`, `tracking -0.02em` vs `-0.018em`, identical `soft={false}` + caret. Effectively the same caption in two colour grades.
- **`italic` + serif — `dustlight` (Fraunces) and `rooftop` (Lora).** Both `weight 400`, `leading 1.42` **both**, `tracking -0.008em` **both**, `size 33` vs `30`, identical `fontStyle: italic` branch, identical caret on.
- **`editorial` (left-aligned) + serif — `shelves` (Lora) and `ember` (Fraunces).** Both `weight 400`, `leading 1.38` **both**, `tracking -0.01em` **both**, `size 31` vs `32`, both use the identical speaker-name + `h-[1px] w-8` rule block above the caption and neither renders the credit row below.
- **`mono` — `lampblack` alone.** Unique `textTransform: "lowercase"`, unique `caretClassName="h-[1.05em]"`, unique `JetBrains Mono` caption. It is also the only scene with a lowercase speaker name in its panel.
- **Light no-blur panels — `dustlight` (`paper`, `#F6EDE1`, `blur: 0`) and `fieldnotes` (`gutter`, `rgba(243,239,230,0.94)`, `blur: 0`)**: the only two `blur: 0` layouts and the only two that use `.scroll-light`.
- **Whole-panel-single-surface — `Paper` (A), `Feed` (B), `Gutter` (B)** are the three layouts that put `p.surface` + `p.radius` + `p.shadow` on the outer container rather than on a header card; every other layout floats a header card or has no surface at all.
- **Session-record duplication (all ten scenes):** identical `source`-less shape, identical `lang: "EN"` and `model: "murmur-stream v2"`, `note`, one `device` string, exactly `script.length` 11–12 lines, and exactly two `speakers`. The scene `id` values `tideline` appear in **both** sets (`cinematic` theme `tideline` and `cinematic-1` scene `tideline`) with unrelated palettes — do not merge them.

# Aggressiveness

Global caveat that applies to every placement below: no design in either set is static. `cinematic` runs `kenburns 46s` on the wallpaper plus a `0.07`-opacity overlay grain that re-shifts every `0.9s` (`steps(4) infinite`); `cinematic-1` runs `drift 46s` plus `grainShift 9s steps(5, end) infinite` at `opacity-[0.05]` and an unconditional white projector radial in `mix-blend-mode: screen`. Nothing here is neon, nothing uses a saturated accent fill, and the only true glow in either set is motel-glow's `0 0 26px`.
