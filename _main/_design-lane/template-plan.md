# 1. Caption layout variants — implementation specs

Shared, once: the panel is the only stage (380×900). Every variant below maps onto
`li.caption > span.caption__text` (settled) + `span.caption__provisional` (forming words).
Sizes quoted are the inventory's stage values; see the 380 px rule in every block.

## bare — cinematic-2 `LiveCaptions.tsx:151-187` (01 rainline, 08 glasshouse, 10 nightswim, 14 dusk-highway, 17 blue-hour)
- structure: `StatusBadge` pill ABOVE (8px `breathe` dot over a 6px dot + "listening"/"paused" at `0.6rem`/`0.3em` uppercase + `LevelBars`), the text row, then a `Meta` row BELOW (note + 1px divider + literal "on-device · 240 ms"). An inline speaker label (`calc(0.66rem*1.15)` = 0.759rem, `0.3em`, uppercase, `color: tone`, `textShadow: none`) sits before the words; empty state = "the room is quiet…" at `opacity 0.4` italic.
- alignment + measure: `caption.align` (`center`, or `left` in 08/14 via `marginLeft: 4vw`, which also strips the badge/meta centring). `maxWidth: caption.maxw` = 52–62ch. Visible-line cap: not stated.
- sizes: `fontFamily: fonts.caption`; `fontSize: clamp(1.02rem, {caption.size}, 2.3rem)` with size 1.5–1.95rem; `fontWeight` 300 or 400; `letterSpacing: caption.tracking` (−0.01em…0.01em); `lineHeight: caption.leading` (1.36–1.46); `textTransform: caption.upper ? "uppercase" : "none"` (no theme sets it true); `fontStyle: italic` only when `caption.italic`.
- colour + forming: settled = `var(--cap-text)`; forming is **IDENTICAL** — `bright`/`dim` are only passed by `karaoke`, so no word is recoloured. `textShadow: 0 2px 26px rgba(0,0,0,.72), 0 1px 6px rgba(0,0,0,.6)` on the text row only. The forming part reads unfinished **only** through the blinking `Caret`: `ml-1.5`, 2px × 0.92em, `background: {tone}`, `borderRadius: 2`, `transform: translateY(0.06em)`, `caretBlink 1.05s steps(1) infinite`, drawn only while `isLive`.
- decoration: none. No background, no border, no radius, no blur, no `soft-in`.
- motion: `wordIn 0.42s cubic-bezier(0.22,1,0.36,1) both` (opacity 0 / translateY(6px) / blur(3px) → 0) on the newest word, keyed so a changed word remounts; `breathe` on the badge dots.
- 380px decision: 52–62ch and `1.72vw` are stage units and neither can apply, so give the wrapper `max-width: 100%` of the column's content box (keep the variant's `px-5` = 20px sides ⇒ ~340px measure) and turn `caption.bottom` (5.2–6.5rem from the viewport) into ordinary flow before the panel's status footer. Keep the caret: with no box, no `bright`/`dim` and the wallpaper gone, the caret is the ONLY marker that a word is still forming.

- sizes: `font-body font-light text-[clamp(20px,2.6vw,30px)] leading-[1.45] text-[var(--caption-ink)]` — the class string is byte-identical between the two themes, so only the palette and `--caption-accent` differ.
- colour + forming: settled `text-[var(--caption-ink)]` (nominal `#63bfb2` seafoam / `#7fbb9c` sage accents are what separate them); the forming part is revealed per CHARACTER — the accent-on-last-word rule is stated for the `fade`/`rise` branch only, so the forming mark here is the per-char animation.
- decoration: none; no glow anywhere in either theme.
- motion: `.cap-char` = `capBlur 0.38s ease both` from `opacity 0 / blur(5px) / letter-spacing 0.08em` — one animation per character, the densest per-element motion of the four modes.
- 380px decision: per-character animation at a small font means the element count per line is the same but each blur is cheaper, so it stays; keep `blur(5px)` exactly as stated and do not add a `will-change`, because the column repaints on every growing partial and a promoted layer per character would be the largest cost in the whole plan.

Two zips disagree on the relationship: cinematic-1 pairs a mono/sans panel body under a serif caption ("DM Mono transcribes and serif narrates"), cinematic-2 reuses the caption family for history row text. In a 380px column: caption family on `.caption__text`, `fonts.ui` on header/footer/history chrome, display family on the wordmark only.
- **Palette structure — always yes.** Every design has background + surface(s) + line + text + dim + accent. `cinematic-2` adds a second accent (`--accent-2`), a dedicated live colour (`--live`), the caption triple `--cap-bg`/`--cap-text`/`--cap-edge`, and the geometry trio `--radius` (4–22px) / `--blur` (14–22px) / `--shadow`. `cinematic-1` splits caption colours (`caption.color/dim/accent`) from panel colours (`panel.text/muted/accent/border/surface/soft`). `cinematic` has 13 fixed var names (`--panel, --panel-2, --ink, --dim, --faint, --line, --accent, --accent-ink, --hover, --caption-ink, --caption-accent, --scrim, --shadow`) whose values the inventory mostly does not record.
- **Backdrop, and the one decision to make once.** Standard stack: opaque page → wallpaper (`transform: scale(1.04)`, one `filter:`) → exactly 2 overlays in order (legibility gradient, then one warm/cool radial pool) → vignette → particles → grain at `mix-blend-overlay`. cinematic-1: wallpaper + `wallFilter` + `wallOverlay` + an unconditional white projector radial in `mix-blend-mode: "screen"`, grain `opacity-[0.05]`, `drift 46s`. There is no stage in this panel, so decide ONCE per theme: keep `--page` + a static grain/vignette pseudo-element as the panel background, drop the kenburns/drift scale (nothing to scale), and keep a particle layer only where the inventory says `particle: "none"` or where you accept motion inside a 380px column.
- **Shared defaults worth hoisting into one base file.** Word machinery: `wordIn 0.42s cubic-bezier(0.22,1,0.36,1) both` (opacity 0 / translateY(6px) / blur(3px) → 0) and `softIn 0.5s cubic-bezier(0.22,1,0.36,1) both` (translateY(10px) → 0, every cinematic-2 variant except `bare`). Caret: 2px × 0.92em, radius 2, `translateY(0.06em)`, `caretBlink 1.05s steps(1) infinite` (cinematic-1's own `.caret` is 2px × 1em, `margin-left: 3px`, `vertical-align: -0.12em`, `opacity: 0.85`, `1.1s steps(2, jump-none)` — the two zips do NOT share a caret). Caption shadows: cinematic-2 `bare` `0 2px 26px rgba(0,0,0,.72), 0 1px 6px rgba(0,0,0,.6)`; cinematic-1 every scene a `0 2px 20–24px` shadow whose dark stop sits at alpha `0.9–0.94`, over a second stop of `rgba(0,0,0,0.65)`–`rgba(0,0,0,0.8)` (both ends of each range are stated per scene). Repeated tokens: `--accent === --live` in 15 of 20 cinematic-2 themes; `maxw 62ch` (6 themes), `bottom 6rem` (9), `size 1.5rem` (6), `leading 1.42` (6), `tracking 0em` (10) — use the repeats as the panel-wide defaults, not as per-theme overrides.
- **DOM mapping and the provisional rule.** `li.caption` is one line; `.caption__text` carries the settled words; `.caption__provisional` carries the words still being spoken. In 5 of cinematic-2's 6 variants forming and settled are styled IDENTICALLY, so give the base file a default `.caption__provisional` that inherits the settled colour and appends the variant's caret (`::after`), and let exactly two things override it: karaoke's `color-mix(--cap-text 30%)` + `blur(1.1px)`, and the cinematic `fade`/`rise` accent on the last shown word. Without that default, a forming word in a `bare`/`glass` theme is invisible as "forming".
- **Column contract (applies to every theme).** Caption box = the panel's content width (the variant's own 20px side padding), `max-width: 100%` — every stated `ch`/px measure (52–68ch, 700–760px) is a stage value that exceeds 380px. Font size: the `clamp(17px, 1.72vw, N)` / `clamp(1.02rem, size, 2.3rem)` middle term is dead at column width, and the stated MAX yields only ~20 characters per line — use the stated clamp FLOOR (17px for cinematic-1, 1.02rem for cinematic-2, 16–22px for cinematic) as the column size; anything between floor and max is a decision, not an inventory value. Two lines per line-block (previous + live) is the documented maximum (the `stack` variant); the panel's live box is a vertical list, so never let a variant wrap beyond two lines.
- **Gaps the inventory does not close (do not invent).** cinematic-1's within-line brightness split and per-word motion (`StreamText.tsx` not among the files read); the site where `cinematic`'s `textShadow` prop is computed; every `cinematic`-zip `vars` value except `#7fb3dc`, `#63bfb2`, `#7fbb9c`, `#92aed4`, `--panel rgba(12,18,15,0.89)`, `--panel-2` at α0.06 and `--panel rgba(240,241,238,0.94)`; and cinematic-1's vignette/grain, which are global (`opacity-[0.05]`, `grainShift 9s steps(5, end) infinite`), not per scene. The id `tideline` exists in BOTH cinematic zips with unrelated palettes — never merge them (this plan ships them as `cine-tideline` and `cine-tideline-body`).
