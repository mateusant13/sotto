## 4. The change (lane B only, by exact anchor)

`CHROME[n]` is **shared by both lanes** — it is emitted into `theme-n.css` AND into
`panel-designs.css` — so editing a literal inside a template rewrites `theme-1..5.css` too,
which this lane is ordered not to touch. The swap therefore runs on the **emitted text of the
`pd-*` designs alone**, in `build()`, guarded by `if t.get('sel')` (the key only lane B sets):

* `PD_CHROME_META` — one **exact anchor pair per rule**, keyed by design.
* `pd_chrome_meta(block, chrome)` — applies them and **FAILS THE BUILD** if an anchor does not
  occur exactly once, so a template that drifts stops the build instead of silently painting
  the family's size again. (This caught its own first cut: the two-line anchors were written
  with `\r\n`, and Python normalises source newlines, so the runtime templates carry `\n`.)
