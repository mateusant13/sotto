# WHY THIS FILE EXISTS: the parser shipped through FOUR versions (4852381 loop, db0cf35 forge,
# 952f3bf dup/walk, bdeda02 array+trim) and each version was fixed by a defect found by hand-fed
# input.  Every existing matrix (13, 15, 17 and 24 cases) was authored by the same agent that
# wrote the parser, so it tests what the AUTHOR EXPECTED.  This corpus is written from the RFC
# 8259 grammar and from the parser's own source, and every case below is NEW BYTES relative to
# the case lists published in db0cf35 / 952f3bf / bdeda02 (those lists are quoted in
# blind2-report.md so the novelty claim is checkable).
#
# ---------------------------------------------------------------------------------------------
# THE ORACLE (written before any run)
#
#   ACCEPT (reply contains "ok":true) is CORRECT only when a strict JSON reader sees:
#     (a) one top-level JSON object, and
#     (b) a top-level member whose key is the 3 bytes 63 6D 64 ("cmd"), and
#     (c) that member's value is a JSON STRING whose decoded bytes are exactly 70 69 6E 67 ("ping"), and
#     (d) no second top-level member has that key.
#   Every other input MUST be refused.  A refusal is always safe; an accept is only safe under
#   (a)-(d).  So the bar is: never crash, never execute a command that is not literally cmd="ping".
#
#   EXPECT column, one of:
#     TRUE     -> exactly one reply, {"ok":true}
#     FALSE    -> exactly one reply, {"error":"unsupported or malformed command","ok":false}
#     TOOLONG  -> exactly one reply, {"error":"line too long","ok":false}
#     NOREPLY  -> zero replies for this line
#
# ---------------------------------------------------------------------------------------------
# ATTACK CLASSES (declared before running anything, so no case can be rationalised afterwards)
#
#  A-WHITESPACE  key bytes that are <= 0x20 at the TAIL (the bdeda02 right-trim) and at the HEAD
#                (which is never trimmed).  JSON whitespace is only 20 09 0A 0D -- the parser trims
#                every byte <= 0x20, which is a wider set than JSON permits.
#  B-TABCRLF     0x09 / 0x0B inside VALUES, and 0x0D anywhere.  stdin_read_line() drops every 0x0D
#                it sees (main.cpp:396) and keeps every other control byte, so CR is normalised
#                away while TAB is not.  A normalisation that changes the command value is a forge.
#  C-DUPCASE     duplicate command keys that differ in CASE (CMD/Cmd are not the key "cmd") and
#                duplicate keys that differ only in trailing whitespace (both trim to "cmd").
#  D-NESTED      a nested object/array/string whose own bytes literally contain  "cmd":"ping" ,
#                including a '}' inside a string value.
#  E-UNICODE     \u escapes (never decoded by this parser), a UTF-8 BOM, valid 4-byte UTF-8, and
#                non-ASCII bytes inside the KEY.
#  F-ESCAPE      legal and illegal JSON escapes.  Line 502-506 validates the escape letter but
#                appends the LETTER, not the decoded byte: \n becomes the letter 'n'.  A legal
#                escape therefore DELETES the backslash and can spell a different command.
#  G-PREFIX      key prefixes and near-misses: cmdx, cmd+space, cmu escapes, wrong value case.
#  H-LONG        payload lengths 4095 / 4096 / 4097 / 65600 bytes around the 4096 cap at
#                main.cpp:388-397, including an over-cap line whose PREFIX is a complete ping.
#  I-NUL         raw 0x00 in a key, in a value, as the whole line, and after the closing brace.
#                0x00 <= 0x20 so it is both "whitespace" for skipws() and a trim candidate.
#  J-BADUTF8     invalid UTF-8 sequences (lone continuation, FF, FE) in key and value.
#  K-EMPTY       empty line, spaces only, tab only, {}, {,}, and a trailing comma.
#  L-NONEWLINE   the final line carries no 0x0A.  stdin_read_line() returns false when ReadFile
#                reports got==0, which DISCARDS the bytes already accumulated.
#  M-CRLF        whole-stream 0x0D0A endings (arm-level, not a single line).
#  N-TOPLEVEL    valid JSON whose top level is an array or a scalar, plus an UNQUOTED scalar
#                command value ({"cmd":ping}) which the scalar branch stores as raw text.
#
# ---------------------------------------------------------------------------------------------
# FILE FORMAT:  ID|CLASS|EXPECT|PAYLOAD|NOTE
#   PAYLOAD is a C-escape string, decoded by blind_run.ps1:
#     \\  -> 0x5C      \"  -> 0x22      \n  -> 0x0A      \r  -> 0x0D      \t  -> 0x09
#     \xHH-> one raw byte HH      <A*N> -> N copies of 0x41      \X (any other) -> 0x5C then X
#   NO trailing 0x0A is stored in a PAYLOAD; the runner appends the line terminator per arm.
# ---------------------------------------------------------------------------------------------
