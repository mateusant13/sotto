## The animation gate (provably producer-driven)

`apply` animates ONLY when `opts.producer` and `opts.prevProducer` are both known,
trimmed, non-empty and DIFFERENT (`producerSwap`, C3a-f). Otherwise it swaps the text
silently and reports `animated: 0`. Measured arms:

- C5 same producer (redux -> redux): animated 0.
- C6 no producer: animated 0.
- C7 no prevProducer and no memory: animated 0.
- C12a insertion with NO explicit prevProducer, but the element remembers a different
  producer from an earlier paint: animated 1 (the memory is a WeakMap keyed by the
  element, and an explicit `prevProducer` wins — C12e).
- C8 a search `<mark>` child: the element is NOT rewritten at all — `skipped: true`,
  `textUnchanged: true`, the original text node is the SAME node, the mark survives.

### 2. `app/panel/panel.js` — the call site (one line)

Anchor (measured today on the live `panel.js`, 139 345 B / 2 885 lines / 2 884 CRLF /
0 bare LF, mtime 2026-10-11T23:27:52.384Z): `addCaption`, the REPLACE-IN-PLACE
branch, `panel.js:934-935`:

    934:     const body = existing.querySelector('.caption__text');
    935:     if (body) body.textContent = text;

Replace line 935 with:

    if (body) { if (window.SottoLetterSwap) window.SottoLetterSwap.apply(body, null, text, { producer: <producer>, prevProducer: <prevProducer> }); else body.textContent = text; }

- `null` as `oldText` makes the module read the element's own current text, so the
  panel never has to hold the old line.
- `<producer>` is the incoming line's producer (the field `caption-formulation.js`
  already stamps as the LAST key of the commit meta).
- `<prevProducer>` MAY BE OMITTED: the module remembers the last producer it painted
  into that element (a WeakMap), so a single-argument `{ producer: ... }` is enough.
- The `else` branch keeps the panel working if the module ever fails to load.
